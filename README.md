This repository contains scripts to generate results for "Genotyping of Indian Himalayas wild-growing cannabis reveals population structure along varying environmental gradients".

To reproduce results, you need to start from raw GBS data available on https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA1111123. 
From these data, you must map variants to the reference genome cs10.
From vcf file, you can proceed to the STRUCTURE analysis and all scripts present in this repository.
STRUCTURE results are needed for fig 1,2 and 3.

Send your questions if you have some !
